Application Overview

User Interface

The main window is split into two panels:

PanelDescription
Left – Contents A tree view listing all 66 Bible books. Each book can be expanded to reveal its chapters. Book nodes show a book icon; chapter nodes show a chapter icon.
Right – Reading pane Displays the text of the selected chapter. The title bar shows the name of the current book. Text is read-only but fully selectable and copyable.

Features

  • Full Bible text – all 66 canonical books, 31 102 verses.
  • Fast navigation – data is stored in SQL Server LocalDB for instant chapter loading.
  • Copy support – select any text and press Ctrl+C.
  • Print support – File > Print or Ctrl+P prints the current chapter with proper pagination.
  • Toolbar – quick access to Print, Copy and About.

System Requirements

  • Windows 10 or later (64-bit)
  • Microsoft Visual C++ 2022 Redistributable (x64)
  • SQL Server Express LocalDB 2019 or later
