Database Setup

Mika's Bible App stores all Bible text in a local SQL Server database (LocalDB). The database is created and populated by a PowerShell script included with the application.

Prerequisites

  • SQL Server Express LocalDB – included with Visual Studio or downloadable from aka.ms/sqllocaldb.
  • PowerShell 5.1 or later (included with Windows 10+).
  • The file data\bbe.txt in the application folder.

Running the Import Script

  1. Open a PowerShell window in the application's root directory.
  2. Run: 
    .\ImportBible.ps1
    The script will create the BibleDB database, the Books and Verses tables, and import all 31 102 verses.
  3. If you need to reimport (e.g. after a failed import), use: 
    .\ImportBible.ps1 -Force
    This clears existing data before importing.
Note: The import can take one to two minutes. Do not close the PowerShell window until it completes.

Verifying the Database

After importing, launch MikasBibleApp.exe. If the Contents panel on the left shows all 66 books, the database is ready.

If the panel is empty or shows an error, check that SQL Server LocalDB is installed and that you have run ImportBible.ps1 successfully.
