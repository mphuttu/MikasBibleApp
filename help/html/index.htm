Welcome to Mika's Bible App

Mika's Bible App is a Windows desktop application for reading the Holy Bible. It presents all 66 books in a convenient tree view on the left and displays the selected chapter in a readable text pane on the right.

Bible Translation: The app includes the Bible in Basic English (BBE), a translation in simple modern English.

What You Can Do

  • Browse all 66 Bible books and their chapters in the left panel.
  • Read the full text of any chapter in the right panel.
  • Select and copy verse text to the clipboard (Ctrl+C or Edit > Copy).
  • Print the current chapter (Ctrl+P or File > Print).

Quick Start

  1. Launch MikasBibleApp.exe.
  2. The left panel shows all Bible books. Click the arrow next to a book to expand its chapters.
  3. Click on any chapter number to load its text in the right panel.
  4. To copy text, select it with the mouse and press Ctrl+C.
